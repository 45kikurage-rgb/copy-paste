# Entryマネージャー

スマートフォン向けの入力補助・応募完了履歴管理サイトです。

## v1で実装した仕様

- フォーマット1 / 2 / 3...を端末内（localStorage）だけに保存
- 各フォーマット直下にURL貼り付け欄と「スタート」
- URLは1件ずつ処理
- 氏名、カナ、住所、電話番号、メール、メモをフォーマットに保存
- 入力後の確認UI
  - キャンセル
  - 変更無しで進む
  - 変更して進む
  - フォーマットも変更
- ページ遷移ボタン確認UI
  - ボタン周辺スクリーンショット表示
  - キャンセル
  - 承諾して押す
  - この操作で応募完了
  - 次回以降このサイト・ページ形式では確認不要
- 試用期間は全ページ遷移ボタンを確認
- 応募完了が確認できた場合だけキャンペーン履歴へ登録
- 完了画面を自動判定できない場合は利用者へ最終確認
- 履歴の編集・削除
- 確認不要設定は利用者ごとに端末内保存
- CSV書き出し / 読み込みで端末変更に対応
- PWA / オフラインキャッシュ

## ページ形式の判定

単純な「先頭100文字一致」は使わず、Helperから渡された次の要素を正規化してSHA-256のページ指紋を作ります。

- hostname
- pathname
- title
- headings
- campaignTexts / identityTexts
- 入力項目ラベル
- ボタン表示

キャンペーンの賞品名など、識別に必要な文言は `campaignTexts` に含めます。ページ指紋が一致しない場合は以前の確認不要設定を適用しません。

## Android Helperとの役割分担

WebブラウザのSame-Origin制限により、EntryマネージャーのWebページだけで他ドメインの入力フォームやボタンを操作したり、画面を切り出したりすることはできません。

そのため以下はAndroid Helperが担当します。

1. 対象URLを開く
2. キャンペーンをページ内容から識別
3. 入力ページまで進む
4. Accessibility等で入力欄へフォーマット値を設定
5. 実際に入力された値と見出しを再取得
6. Entryマネージャーへ入力確認を要求
7. 次ページボタン周辺を切り出してEntryマネージャーへ確認要求
8. 承諾後にボタンを押す
9. 応募完了画面・完了文言を検出し、成功時だけ完了通知

### Bridgeイベント

サイトは以下の入力を受けられるようにしています。

- `INPUT_REVIEW`
- `ACTION_REVIEW`
- `CAMPAIGN_IDENTIFIED`
- `COMPLETION_DETECTED`
- `COMPLETION_UNKNOWN`
- `ACTION_FAILED`

ブラウザ側は `window.EntryManagerBridge` も公開しています。

## 保存先

個人情報、応募履歴、確認不要ページ設定はCloudflareやGitHubには送信しません。利用端末内に保存します。

CSVバックアップには個人情報が平文で含まれるため、取り扱いに注意してください。
